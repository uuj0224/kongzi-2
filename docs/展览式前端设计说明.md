# 现代东方文化展览式前端

用户确认方向：现代东方文化展览，桌面 Web，替换旧的常驻侧栏和孤立立绘。顶部导航、历史抽屉、完整手卷画面与输入入口共同形成首屏；问答专注阅读；文库采用篇章目录与正文布局。

主画面由内置 image_gen 生成，页面使用 `frontend/public/images/confucius-study.webp`（1920×960，约220KiB）。形象为 AI 艺术创作，不是真实历史肖像。对话头像继续使用上一版人物素材。

首页标题使用本地自托管 Noto Serif SC 字形子集，来源 Google Fonts；许可位于 `frontend/public/fonts/OFL.txt`。常规正文使用系统黑体；古文阅读保持宋体回退。不使用外部字体请求。
