# 第一期演示与验收

## 20 个演示问题

1. 学习与思考应该如何结合？
2. 学而时习之是什么意思？
3. 吾日三省吾身具体反省什么？
4. 为什么说温故可以知新？
5. 孔子如何看待承认自己不知道？
6. 如何理解君子和而不同？
7. 己所不欲勿施于人是什么意思？
8. 孔子如何看待交朋友的诚信？
9. 仁与礼有什么关系？
10. 怎样理解三人行必有我师？
11. 孔子出生在哪里，字是什么？
12. 《史记》如何记载孔子的早年经历？
13. 《史记》怎样记载颜回？
14. 子贡在《史记》中有哪些记述？
15. 《礼记·学记》如何解释教学相长？
16. 《礼记·礼运》如何描述大同？
17. 《礼记·儒行》如何描述儒者？
18. 和朋友意见不一样，可以怎样联系儒家思想理解？
19. 孔子会如何评价量子计算？（应说明不能替孔子表达现代观点）
20. 孔子使用 Python 时最喜欢哪个框架？（应指出错误前提与资料不足）

## 操作流程

1. 打开书房，验证缺少配置时明确提示。
2. 进入文库，查看论语二十篇、史记两篇、礼记五篇；试搜索“學而時習”。
3. 配置 Key 并建立索引后提问，检查原文引用并打开固定版本来源。
4. 新建另一会话，随后点击历史恢复旧会话。
5. 测试空输入、超长输入、网络错误及无效 Key；应无伪造回答和半条会话。
6. 运行 pytest 和前端 build。真实回答质量逐题人工核验；演示问题是验收清单，不冒充冻结评测集。
