《论语》原定参考维基文库；为响应 GitHub 扩展资料要求，本次改用固定版本的 chinese-poetry 底本，避免混用版本章次。GitHub 链接是数字资料来源，不等于学术权威背书。

chinese-poetry 的 MIT 许可全文保存在 data/raw/LICENSE.chinese-poetry。殆知阁仓库未发现独立 LICENSE，不将其描述为 MIT 授权。古籍作品年代久远，但现代录入、标点和编排可能存在额外权利；当前资料用于本地课程研究，公开发布数据集前需另行核实，不承诺任意再发布。

导入只选取指定古籍原文，不自动纳入当代译注。史记按史传记述标记，礼记按儒家经典标记，不将其中全部内容归为孔子亲口所说。文本保留底本字形与标点；检索副本用 OpenCC 规范化。长篇项目分段号不是古籍通行章次。知识库缺乏跨版本校勘，适用于学习演示。

notes.json 为项目编写的学习释义，共 80 条，以“项目整理、待教师复核”标注；未经教师或古籍专家审核，不宣称专业审校。可在浏览页逐条核对。

scripts/import_data.py 根据已下载快照确定性构建 passages.json，保留固定来源链接、提交号及原始文件哈希；不会自行生成古籍原文。重新获取原始快照时应使用 sources.json 中的固定提交号，不使用浮动 master。
